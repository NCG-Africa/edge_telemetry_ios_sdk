# Migrating from EdgeRum v1.0.0-alpha.2 to v1.0.0-alpha.N

This is the one breaking batch before GA (epic #216, F29). It fixes the
SDK's own naming incoherence in a single release so GA `1.0.0` starts
from a stable vocabulary. **Host Swift code barely changes** — one config
removal. **Dashboards, queries and backend routing change a lot**: event
names split, keys are renamed or deleted, and stack frames change format.
The backend (Processor) must ship its side first.

The contract for every row below is
[`docs/catalogue/ios-data-catalogue.md`](../catalogue/ios-data-catalogue.md) §9.

---

## What's changing

**Public Swift API**

- `EdgeRumConfig.resolveLocation` and `EdgeRumConfig.locationProviderUrl`
  are removed (source break). Set `config.location` yourself.
- `EdgeRum.time(_:)` keeps its signature; its wire name changes (below).
- Host attribute keys under an SDK-reserved prefix are now dropped (below).

**Event names**

- `captureError` emits **`app.error`** (was `app.crash` + `cause = "AppError"`).
  Sampled; rides the normal flush.
- The hang watchdog emits **`app.hang`** (was `app.crash` + `cause = "Hang"`).
  Sampled; rides the normal flush.
- **`app.crash`** is native-crash replay (PLCrashReporter) only. Forced-emit;
  flushes immediately.
- `screen.duration` is no longer emitted by UIKit or SwiftUI and is gone
  from the allowlist. The Processor derives dwell from `navigation` (#144).
- Allowlist is now 13 names: `session.started`, `session.finalized`,
  `app_lifecycle`, `page_load`, `navigation`, `http.request`,
  `user.interaction`, `network_change`, `user.profile.update`,
  `custom_event`, `app.error`, `app.hang`, `app.crash`.
- Forced-emit set unchanged: `session.started`, `session.finalized`,
  `app.crash`, `network_change`.

**Renames**

| old | new | on |
|---|---|---|
| `navigation.name` | `navigation.screen` + `navigation.kind = "manual"` | `navigation` from `trackScreen` |
| `interaction.target_id` | `interaction.name` | `user.interaction` |
| — | `interaction.name_source` gains `"host"` | `.edgeRumTrackTap` |
| `network.is_expensive` / `network.is_constrained` | `network.expensive` / `network.constrained` | `network_change` |
| `error.type` | `error.class` | `app.error` |
| `crash.timestamp` | `hang.timestamp` | `app.hang` |
| `crash.thread.main_stack` | `hang.stack` | `app.hang` |
| host `metricName` from `EdgeRum.time(name)` | `metricName = "custom_timer"` + `timer.name = name` | timer items |

**Deletions**

| deleted | use instead |
|---|---|
| `cause` | the event name (`app.error` / `app.hang` / `app.crash`) |
| `crash.fatal` | — (was constant `true`) |
| `navigation.type` | — (was constant) |
| `page_load.cold_start` | `page_load.prewarmed` |
| `interaction.screen` | the `screen.name` rider (on every event since F28) |
| `http.url`, `resource.url` | `http.host` + `http.path`, `resource.host` |
| `screen.duration` + `screen.kind`, `screen.duration_ms` | dwell derived from `navigation` |
| `value` copy inside metric `attributes` | the item-level `value` (unchanged) |

**Value and shape changes**

- Free-text `http.error` → `http.error_domain` (string) + `http.error_code` (int).
- `metricName` allowlist of 6: `resource_timing`, `long_task`,
  `frame_render_time`, `memory_usage`, `cpu_usage`, `custom_timer`.
- `memory_usage` `value` is now **MB** (was kB). `memory.*_kb` keys are unchanged.
- Stack frames on `error.stack`, `long_task.stack`, `hang.stack` are now
  `image +0x<offset> <hint>`. Siblings `error.binary_images`,
  `long_task.binary_images`, `hang.binary_images` carry a JSON string
  `[{"name","uuid"}]` of the referenced images (`uuid` = 32 lowercase hex,
  PLCrashReporter's `imageUUID` format).
- Degradation markers (integer counts, omitted when zero):
  `error.stack.truncated`, `long_task.stack.truncated` (bytes removed);
  `hang.stack.truncated` (frames removed — replaces the in-string
  `…N more…`); `crash.binary_images.dropped`, `crash.registers.dropped`.
  The `crash.report_json` size-cap fallback drops unreferenced images first.
- **Sessions.** `session.finalized` is emitted **only on rotation** and
  carries `session.end_time` (the ended session's last activity, ISO 8601)
  and `session.rotation ∈ {idle, max_duration}`. `session.started` on a
  rotation carries `session.rotation` too. Sessions are capped at **4 h**.
  Resign, terminate and `stop()` only flush; they emit nothing. A session
  that expired while the app was not running is finalized at the next
  `start()`.
- **Reserved namespaces.** Host keys passed to `track`, `trackScreen`,
  `RumTimer.end`, `.edgeRumScreen` and `.edgeRumTrackTap` that start with
  an SDK prefix are dropped. The event carries `host_attributes.dropped`
  (int, omitted when zero); dropped keys are logged when `debug == true`.
  `captureError(context:)` keys are unaffected (they are prefixed
  `crash.context.`). Reserved prefixes: `app.` `device.` `network.`
  `session.` `user.` `sdk.` `navigation.` `interaction.` `http.`
  `resource.` `crash.` `error.` `hang.` `action.` `rum.` `screen.`
  `lifecycle.` `page_load.` `launch.` `long_task.` `frame.` `memory.`
  `cpu.` `timer.` `event.` `breadcrumb.` `previous_session.`
  `traceparent.` `host_attributes.`, plus two more reserved for
  request-correlation work (full list: catalogue §9 /
  `HostAttributes.reservedPrefixes`).

**Auto-capture defaults, dependency floors:** unchanged.

## Why

**One name, one flush policy.** `app.crash` carried handled errors, hangs
and native crashes, routed by `cause`. A replayed crash must bypass
sampling and flush (the process already died); a handled error or a hang
must not. Splitting the name lets the Processor route on `eventName` and
lets the SDK apply one policy per name.

**One spelling per fact.** Each rename fixes iOS's own incoherence (two
screen keys, two label keys, `is_`-prefixed and plain network flags, a
`crash.*` key on a non-crash event). Renames never chase another
platform's spelling.

**Privacy.** `http.url` / `resource.url` and free-text `http.error`
carried full URLs with query strings. Typed `http.error_domain` /
`http.error_code` are enough to classify failures.

**Bounded names.** Host timer names in `metricName` made the metric name
space unbounded; `custom_timer` + `timer.name` keeps it at six.

**Symbolication.** Absolute addresses are useless off-device under ASLR.
Image-relative offsets plus the image UUID let the backend symbolicate
against dSYMs (catalogue §10 P18).

**Session pairing.** Emitting `session.finalized` on every resign produced
many per session; one per ended session with `session.end_time` makes
`started → finalized` pairing valid.

**No shadowing.** A host key like `user.email` in `track` could silently
overwrite an SDK key. Reserved prefixes stop that.

**Dead config.** `resolveLocation` was never wired; no request was ever made.

## Wire format impact

**Yes.** Rollout order: **Processor first**, then this iOS alpha
(catalogue §10 P3–P5, P8, P14, P18).

- Event names: `app.error`, `app.hang` added; `app.crash` narrowed to
  native replay; `screen.duration` no longer sent.
- Keys renamed / deleted / added: every row in "What's changing" above.
- `metricName`: closed set of 6; `custom_timer` + `timer.name` new;
  `memory_usage` `value` unit kB → MB.
- Stack frame format and `*.binary_images` siblings.
- `session.finalized` cardinality (one per ended session), new
  `session.end_time`, `session.rotation`.
- Envelope: unchanged.

## Public API diff

```swift
// Before — v1.0.0-alpha.2
var config = EdgeRumConfig(apiKey: "edge_live_abc123", endpoint: endpoint)
config.resolveLocation = true
config.locationProviderUrl = URL(string: "https://ipapi.co/json/")

// After — v1.0.0-alpha.N
var config = EdgeRumConfig(apiKey: "edge_live_abc123", endpoint: endpoint)
config.location = "Nairobi/Kenya"   // resolve it yourself if you need it
```

```swift
// Unchanged signature; wire name changes.
let timer = EdgeRum.time("checkout.submit")
timer.end()
// Before: metricName = "checkout.submit"
// After:  metricName = "custom_timer", timer.name = "checkout.submit"
```

```swift
// Host keys under a reserved prefix are now dropped.
EdgeRum.track("checkout_started", attributes: ["user.is_member": true])     // dropped; host_attributes.dropped = 1
EdgeRum.track("checkout_started", attributes: ["loyalty.is_member": true])  // sent
```

## Auto-mappable changes

- Delete any `resolveLocation` / `locationProviderUrl` assignment; the
  compiler flags each one. No codemod ships.
- Backend queries: the rename table above is a mechanical find/replace on
  key and event names.

---

## Manual changes needed

- **Host attribute keys.** Audit `track`, `trackScreen`, `RumTimer.end`,
  `.edgeRumScreen` and `.edgeRumTrackTap` call sites for keys under a
  reserved prefix and rename them (e.g. `user.is_member` →
  `loyalty.is_member`). Watch `host_attributes.dropped` in debug builds.
- **Location.** If you relied on `resolveLocation`, set `config.location`.
- **Dashboards.** Re-key error/hang/crash panels on `eventName`; move
  host-timer panels to `timer.name`; rescale `memory_usage` (÷1024);
  drop panels on `screen.duration` from iOS (use the Processor's derived
  dwell); expect one `session.finalized` per session.
- **Stack parsers.** Anything keyed on absolute addresses breaks; parse
  `image +0x<offset> <hint>` and join to `*.binary_images`.
- **Tests.** Fixtures asserting old keys, `cause`, or `screen.duration`
  must be updated.

## Also in this release (tranches 1–3)

Non-breaking, already on this branch:

- **T1 (F26).** The `flushInterval` timer is actually armed (quiet sessions
  flush on schedule); the offline queue cap counts events (default 200,
  was ~6,000 effective); `hang.cpu_usage` is populated (per-core percent,
  may exceed 100).
- **T2 (F27).** `EdgeRum.clearUser()` (drop the `identify()` profile on
  logout); `EdgeRum.resetIdentity()` (new `device.id` + `user.id`); host
  identity keys (`user.name` / `user.email` / `user.phone`) are no longer
  written to the crash sidecar; `captureButtonTitles` opt-in (default
  off); `interaction.name_source` on every tap.
- **T3 (F28).** Riders `screen.name`, `device.orientation`, `app.state` on
  every event; `device.family` context attribute;
  `navigation.previous_screen`.
- **T5 (F30).** `frame_render_time` is one item per motion window (touch
  or screen transition, ≤ 10 s) with `frame.window_ms`; `memory_usage`
  every 30 s (was 10 s) with the last observed `memory.pressure`;
  `cpu_usage` (per-core percent) on the same tick; periodic items pause
  while inactive, on Low Power Mode or at thermal `serious`+.
